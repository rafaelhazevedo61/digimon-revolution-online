# Mapa de drops e recompensas

Referência das planilhas `DRO_Mapeamento_Consolidado_de_Drops (1).xlsm` e `DROPS - ATT 020926(1).xlsm`. As tabelas reproduzem o mapeamento da planilha consolidada, incluindo propostas de balanceamento. Para confirmar o que está ativo em um ambiente, consulte as Loot Tables do catálogo e as migrations aplicadas.

O percentual em negrito é o valor informado pela planilha para a faixa de raridade. Os percentuais junto aos itens mantêm a notação da planilha. As abas podem usar bases diferentes para esses valores, portanto use a Loot Table do jogo para calcular probabilidades efetivas. A faixa de raridade da tabela pode diferir da raridade da peça concedida.
